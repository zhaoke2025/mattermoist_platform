# DocSpace 初始化、外部协作与备份恢复验收

本文档对应 ZZJ-31，并补充服务器到位后的管理员初始化、备份和恢复检查。所有测试使用无敏感信息的样例文档。

## 测试角色

准备三个彼此独立的账号：

| 角色 | 用途 |
| --- | --- |
| DocSpace 管理员 | 初始化、建房、授权和审计 |
| 内部普通用户 | 验证内部查看、编辑和隔离 |
| 外部测试用户 | 使用公司外部邮箱验证客户或供应商访问 |

验收时使用普通浏览器和无痕窗口，避免管理员登录状态影响结果。

## 管理员初始化

- [ ] 正式域名和 HTTPS 可用，浏览器无证书警告。
- [ ] 创建首个管理员并启用强密码；若版本支持，启用多因素认证。
- [ ] 设置组织名称、时区和邮件发送配置。
- [ ] 禁用不需要的公开注册入口。
- [ ] 确认默认新用户和访客权限符合最小权限原则。
- [ ] 创建内部用户、外部用户和测试协作房间。
- [ ] 上传 DOCX、XLSX、PPTX 和 PDF 样例。
- [ ] 记录部署版本、镜像摘要、配置文件位置和数据卷位置。
- [ ] 验证 MySQL、OpenSearch 和管理端口未暴露到公网。

## 外部协作测试

在协作房间中执行并记录每项结果：

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| E01 | 管理员邀请外部测试邮箱 | 外部用户收到有效邀请并能完成登录 |
| E02 | 外部用户打开指定房间 | 只能看到被授权的房间 |
| E03 | 外部用户打开未授权房间地址 | 被拒绝访问，且不泄露文档列表 |
| E04 | 授予查看权限后打开文档 | 可以查看，不能修改内容 |
| E05 | 授予编辑权限后修改样例文档 | 可以保存，内部用户能看到变更 |
| E06 | 降低权限后再次编辑 | 新权限生效，编辑操作被拒绝 |
| E07 | 生成允许的分享入口 | 指定外部用户可访问，未授权用户不可访问 |
| E08 | 撤销邀请或分享 | 原入口立即或在可接受缓存时间内失效 |
| E09 | 管理员查看操作记录 | 能识别外部用户的访问或修改行为 |
| E10 | 从 Mattermost 固定入口进入 | 有权限用户进入正确房间，无权限用户不能绕过授权 |

如所选版本不支持某种分享期限、密码或审计能力，应记录为版本能力缺口，不能把“未验证”写成“通过”。

## 文档与持久化测试

- [ ] 内部用户可以上传、下载和重命名文档。
- [ ] DOCX、XLSX、PPTX 可以在线打开、编辑并保存。
- [ ] PDF 可以正常查看。
- [ ] 两个用户同时编辑样例文档时，变更可见且无文件损坏。
- [ ] 正常重启 DocSpace 容器后，账号、房间、权限和文档仍存在。
- [ ] 重启不影响现有 Mattermost、ONLYOFFICE Docs 和 filebot。

## 备份前登记

正式备份命令以服务器上最终选定的 DocSpace 固定版本为准。首次备份前必须登记：

- 部署源码标签和所有容器镜像摘要。
- 环境变量文件、反向代理和证书配置的位置。
- `app_data`、`mysql_data`、`os_data`、日志和字体等实际持久化目录。
- 管理员账号恢复方式和密钥保管人。
- 备份目标、保留周期、加密方式和恢复负责人。

密码、Token、私钥不能写进本文档或验收截图。

## 备份检查

- [ ] 备份前确认服务健康，记录开始时间和部署版本。
- [ ] 备份 MySQL 数据及 DocSpace 应用文件，保证两者来自一致的时间点。
- [ ] 保存部署配置、固定版本和镜像摘要。
- [ ] 根据最终版本说明备份或重建 OpenSearch 数据。
- [ ] 备份写入独立磁盘、NAS 或对象存储，不只保留在 DocSpace 数据盘。
- [ ] 备份文件加密并生成校验值。
- [ ] 设置保留周期，并验证旧备份可按策略清理。

禁止使用 `docker compose down -v`，该命令可能删除持久化卷。

## 恢复演练

恢复演练应在隔离环境执行：

1. 准备空目录或临时恢复服务器，使用相同的固定版本。
2. 恢复部署配置、数据库和应用文件。
3. 启动服务并检查所有容器健康状态。
4. 使用管理员和普通用户分别登录。
5. 检查房间、成员、权限、历史文档和在线编辑。
6. 抽查备份前记录的样例文档内容和校验值。
7. 记录恢复开始时间、完成时间、问题和处理方法。
8. 演练成功后清理隔离环境，不覆盖生产数据。

只有完成一次恢复演练，备份项才算验收通过。
